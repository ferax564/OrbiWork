OrbiWork

Your coding agents, on your machine. Nothing phones home.

OrbiWork is a minimal console for the coding agents you already use, such as Claude Code and Codex. Threads, approvals, a terminal, diffs and git worktrees in one fast interface.

Get the source on GitHub

What privacy-first means here

  • Off by default Analytics, remote configuration and update checks do not run unless you turn them on. A few remaining lookups are listed in the roadmap and are being removed.
  • No account, no hosted relay Reach your machine over your own network, Tailscale or SSH. No third party sits in the path.
  • Your subscriptions OrbiWork resells nothing. It drives the agents you are already signed in to.
  • Open source MIT licensed. Read it, build it, change it.

Status

Early. There are no installers, store apps or hosted services yet. You build it from source with Node 26 and pnpm: 

git clone https://github.com/ferax564/OrbiWork
cd OrbiWork
pnpm install
pnpm dev
