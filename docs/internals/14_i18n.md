# UI copy

OrbiWork ships in English only. There is no language setting and no locale detection; a `language` key in old saved client settings is ignored on decode.

UI copy still goes through `gt-react` (web) and `gt-i18n` (desktop main process, `packages/client-runtime`, `packages/shared`). It costs nothing at runtime: GT starts with English as its only locale and a loader that returns nothing, so it never loads a catalog or calls GT's CDN or API. Keep the existing call sites; do not rewrite them.

## Which API

| Where the text is                                                     | Use                                                                                                |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| JSX children, including `<code>`, `<strong>`, links                   | `<T>…</T>`, values in `<Var>`, plurals with `<Plural n={n} one={…} other={…} />`                   |
| A prop or string inside a component (`title`, `aria-label`, tooltips) | `const gt = useGT()`, then `gt("Discard draft")`                                                   |
| A constant table (settings index, menus, command registry)            | `msg("Diagnostics")` in the table; `const m = useMessages()` and `m(entry.label)` where it renders |
| Outside React: toasts, stores, announcements, alerts                  | `m(msg("An error occurred."))`, `m` from `~/i18n/messages` (desktop: `apps/desktop/src/i18n`)      |

Import `T`, `gt`, `msg` and the hooks straight from `gt-react` (or `gt-i18n`): `gt generate` only finds strings whose functions come from a GT package.

## Writing strings

- Variables: `gt("{shortcut} to undo", { shortcut })`.
- Plurals: `gt("{count, plural, one {{count} thread} other {{count} threads}}", { count })`. Use `{count}`, not `#`: `#` formats 1234 as "1,234". When the singular has no number ("View browser"), use `=1 {…}`.
- ICU syntax: an ASCII apostrophe next to `{` or `}` starts a quote, so write `''{name}''` to print `'name'`. Literal braces need `'{'`. Never put tags in `gt()` text; markup goes in `<T>`.

## The English catalog

`gt generate` writes the strings it finds to `apps/web/src/i18n/translations/en.json` and `apps/desktop/src/i18n/translations/en.json`. Nothing loads them at runtime; they keep the copy reviewable in one place. After changing copy run `vp run i18n:generate` in the app; `vp run i18n:check` (CI) fails when a catalog drifts from the source. Do not edit them by hand.

`orbiwork/no-untranslated-copy` reports copy that bypasses these helpers. For text that must stay literal (product names, commands, user content, anything sent to an agent), write `// oxlint-disable-next-line orbiwork/no-untranslated-copy -- <why>`.
